# 아무거나 버스터

점심 메뉴를 고르고, 같이 먹을 장소를 정하고, 식후 커피 내기까지 한 곳에서 해결하는 직장인용 점심 도구입니다.

[서비스 바로가기](https://amugeona-buster-6eda848df67d.herokuapp.com/)

## 주요 기능

### 오늘의 식단

- 삼성 계열 구내식당 지점별 식단 조회
- 날짜와 아침·점심·저녁·야식·전체 메뉴 필터
- 메뉴별 칼로리, 가격, 운영 상태 표시
- 식단 코너별 별점과 한줄평 작성 및 조회

### 카카오톡 식단 알림

- 카카오 계정 연결 후 구내식당, 요일, 발송 시간 설정
- 설정한 시간대에 맞는 식단을 카카오톡으로 발송
- 식단을 확인할 수 없는 날에도 임의의 메뉴 대신 상황을 안내

### 메뉴 투표

- 로그인 없이 닉네임만으로 방 생성
- `ROOM-XXXXXX` 코드와 공유 링크로 간편하게 참여
- 후보 메뉴를 고른 뒤 참여자별 좋아요·싫어요 투표
- 대기실과 투표 진행 상황은 WebSocket으로 실시간 동기화
- 모두가 싫어한 메뉴를 우선 제외해 최종 메뉴 결정

### 위치 기반 식당 추천

- 장소를 검색하거나 현재 위치를 사용해 약속 장소 확정
- 선택한 좌표 반경 1km 안에서 우승 메뉴와 가까운 식당 검색
- 메뉴 검색 결과와 주변 보완 식당을 구분해 표시
- 거리, 주소, 전화번호, 카카오맵 링크와 지도를 함께 제공

카카오 장소 리뷰를 그대로 가져오는 대신, 서비스 안에서 식단 코너별 별점과 한줄평을 직접 작성하고 공유합니다.

### 식후 커피내기

한 기기에서 2~8명이 바로 진행할 수 있는 다섯 가지 게임을 제공합니다.

1. **주사위 2개** — 두 주사위 합계가 높은 사람 또는 낮은 사람이 커피 담당
2. **반응속도 대결** — 신호가 바뀌는 순간 눌러 기록 비교
3. **5초 맞추기** — 5초에 가장 가까운 사람이 승자
4. **지뢰 피하기** — 차례대로 칸을 골라 지뢰를 피하는 게임
5. **한 명 뽑기** — 참여자 중 한 명을 무작위 추첨

참여자 이름과 최근 결과는 사용하는 기기에 저장하며, 모바일에서는 게임을 고른 뒤 시작 버튼이 화면 하단에 계속 보입니다.

## 사용 흐름

```text
식단 확인 → 메뉴 투표 방 만들기 → 장소·후보 메뉴 선택
→ 참여자 초대 → 메뉴 투표 → 주변 식당 확인 → 커피내기
```

## 기술 스택

| 영역 | 사용 기술 |
| --- | --- |
| Backend | Java 21, Spring Boot 3.3, Spring Data JPA |
| Frontend | React 18, TypeScript, Vite |
| 실시간 통신 | Spring WebSocket(STOMP), SockJS |
| Database | PostgreSQL, H2 |
| 외부 연동 | Welstory 식단 API, Kakao OAuth·메시지·Local·Maps API |
| 배포 | Heroku |

## 프로젝트 구조

```text
backend
├── domain                  # 방, 메뉴, 투표 등 핵심 규칙
├── application             # 유스케이스와 포트
└── adapter
    ├── in                  # REST, WebSocket, 스케줄러
    └── out                 # JPA, 카카오·웰스토리 연동

frontend
└── src/features
    ├── meals               # 식단과 한줄평
    ├── rooms               # 메뉴 투표 방
    ├── games               # 커피내기 게임
    └── settings            # 카카오톡 알림 설정
```

백엔드는 메뉴 투표 규칙과 외부 API·저장소를 포트와 어댑터로 나눠 관리합니다. 덕분에 식당 검색이나 저장 방식이 바뀌어도 투표 규칙까지 함께 바꿀 필요가 없습니다.
